# STAR-Nuker
파이썬(py)로 제작되었으며 exe로 빌드된  디스코드에서 가장 빠른 서버 테러(Nuker) 툴, STAR-Nuker입니다. 해당 프로그램은 전체 한국어를 지원합니다!



### STAR-Nuker 사용방법

- `config.json` 파일에 본인의 봇 토큰(Bot Token)과 채널/역할/메시지 내용을 입력합니다.
- 프록시(Proxies)를 설정합니다. (선택 사항)
- `STAR-Nuker.exe` 파일을 실행합니다.

## STAR-Nuker의 기능
- [x] HTTP/s 프록시 지원 (`[ip:port]` 및 `[user:pass@ip:port]` 형식)
- [x] 모든 멤버 차단(Ban)
- [x] 모든 멤버 추방(Kick)
- [x] 활동 없는 멤버 정리(Prune)
- [x] 채널 대량 생성
- [x] 역할(Role) 대량 생성
- [x] 채널 모두 삭제
- [x] 역할 모두 삭제
- [x] 이모지 모두 삭제
- [x] 채널 메시지 도배(Spam)
- [x] `config.json` 파일에서 채널/역할 이름 및 메시지를 무작위(Random) 선택하는 기능
